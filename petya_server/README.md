# Сервер Пети (голосовой ИИ)

Запускается на **отдельном компьютере в локальной сети** (не на том, где играете).
Этот компьютер распознаёт вашу речь, генерирует ответ Пети и озвучивает его.
Игра стучится к нему по IP этого компьютера.

## Установка

1. Установите Python 3.10+ (https://python.org).
2. В этой папке выполните:
   ```
   pip install -r requirements.txt
   ```
3. Установите Ollama (https://ollama.com) - это отдельная программа, не Python-пакет.
   После установки скачайте модель:
   ```
   ollama pull llama3.2
   ```
   Это лёгкая модель (3B) - должна нормально идти на 16 ГБ ОЗУ даже без видеокарты.
   Если ноутбук мощнее (32 ГБ+ или есть видеокарта) - можно взять модель покрупнее,
   например `llama3.1` (8B) или `mistral` (7B), для более живых ответов. Если,
   наоборот, и `llama3.2` идёт медленно - попробуйте `phi3` (тоже около 3.8B, но
   быстрее на слабом CPU) или `llama3.2:1b` (совсем маленькая и быстрая, ответы
   попроще). В любом случае замените `OLLAMA_MODEL` в `petya_server.py` на то,
   что скачали.
4. Установите Piper (озвучка):
   ```
   pip install piper-tts
   ```
   Скачайте русский голос со страницы
   https://github.com/rhasspy/piper/blob/master/VOICES.md - нужны ДВА файла:
   `ru_RU-irina-medium.onnx` и `ru_RU-irina-medium.onnx.json` (или другой
   русский голос на выбор). Положите оба файла в эту же папку
   (`petya_server/`). Если взяли другой голос - поменяйте `PIPER_VOICE`
   в `petya_server.py`.

## Запуск

```
python petya_server.py
```

Должно появиться `Petya AI server listening on port 8765`. Не закрывайте окно,
пока хотите, чтобы Петя отвечал.

## Узнать IP этого компьютера

В командной строке Windows:
```
ipconfig
```
Ищите `IPv4-адрес` (обычно вида `192.168.1.xxx`) в том сетевом адаптере, через
который этот компьютер подключён к той же сети, что и компьютер с игрой.

## Настройка игры

На компьютере, где запущена игра, нужно один раз запустить игру (чтобы файл
создался), затем открыть файл:

```
%APPDATA%\Godot\app_userdata\SnowClean\petya_ai_server.cfg
```

и прописать там IP и порт этого сервера:

```
[server]
host="192.168.1.xxx"
port=8765
```

## Брандмауэр

Windows может заблокировать входящие подключения на порт 8765 - при первом
запуске сервера должно появиться окно с запросом разрешить доступ, нажмите
"Разрешить" (для частных/локальных сетей).

## Если что-то не работает

- Убедитесь, что Ollama запущена (иконка в трее) и модель скачана (`ollama list`).
- Проверьте, что оба файла голоса Piper (`.onnx` и `.onnx.json`) лежат рядом
  со скриптом и называются так же, как в `PIPER_VOICE`.
- В консоли, где запущен `petya_server.py`, будут видны ошибки при обращении к
  Ollama или Piper - смотрите туда в первую очередь.
- Убедитесь, что оба компьютера действительно в одной локальной сети (пинг
  с одного на IP другого должен проходить).
